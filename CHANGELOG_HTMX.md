# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- HTMX integration for dynamic content updates
- HTMX attributes on navigation elements and forms
- JavaScript loading state management
- HTMX-aware handler logic

### Changed
- Updated base layout template to include HTMX library
- Modified navigation links to use HTMX for page transitions
- Enhanced form elements with HTMX attributes for submission
- Added loading indicators for HTMX operations

### Fixed
- Resolved issues with partial HTML rendering in HTMX context

## [0.1.0] - 2023-07-15

### Added
- Initial HTMX implementation
- Basic template modifications for HTMX support
- JavaScript for loading state management

### Changed
- Updated handler functions to detect and respond to HTMX requests
- Modified form submission to work with HTMX

### Fixed
- Ensured backward compatibility with non-HTMX requests
- Fixed navigation element HTMX attributes
